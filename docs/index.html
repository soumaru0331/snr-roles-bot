使用例
実際の動作イメージ。スラッシュコマンドから即座に検索できます。
/search コマンド — ローマ字で「samu」と入力するだけで侍がヒット
/roles コマンド — 陣営ボタンで役職一覧をページ表示
コマンド一覧
すべてスラッシュコマンドで入力補完つき。
/search
役職を名前で検索します。ひらがな・カタカナ・ローマ字・漢字に対応。部分一致でOK。
/search samu　→　侍
/search いびる　→　イビルゲッサー
/search hadou　→　波動砲
/roles
SNRの全役職を陣営別に一覧表示します。ボタンで陣営を選択し、ページングで閲覧できます。
/roles　→　陣営選択ボタンを表示
